# ES6_basic

## 0. Const or let?

### Description
This project focuses on understanding the usage of `const` and `let` in ES6 JavaScript. The goal is to modify two functions to use proper variable declarations based on whether the variable should be reassigned or not.

### Files
- `0-constants.js`: Contains the functions `taskFirst` and `taskNext` which are modified to use `const` and `let` appropriately.

### Tasks
1. **taskFirst**: Instantiate variables using `const`.
2. **taskNext**: Instantiate variables using `let`.

### Usage
To test the functions, run:
```bash
npm run dev 0-main.js
