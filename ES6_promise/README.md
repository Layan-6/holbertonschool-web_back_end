## Learning Objectives
By the end of this project, you should be able to:
- Understand what Promises are and why they are used
- Create and return a Promise
- Handle resolved and rejected states
- Chain Promises using `.then()` and `.catch()`
- Use `Promise.all()` and `Promise.race()`

## Requirements
- All code must be compatible with ES6
- Use `export default` for functions
- Proper error handling with Promises
